# 🍽️ Restaurant Food Order Form

A simple and attractive **Restaurant Food Order Form** developed using HTML, CSS, JavaScript, and Bootstrap. This project allows users to add food items, manage their order list, remove items, and calculate the total amount.

## ✨ Features

- **Add Food Items:** Enter food name, price, category, and description.
- **Multiple Items:** Add multiple food items to an order.
- **Food Categories:** Select from Punjabi, Chinese, South Indian, Cold Drink, Buttermilk, and Dessert.
- **Order Summary:** Display all added food items.
- **Remove Items:** Remove unwanted items from the order.
- **Automatic Total:** Calculate the total amount automatically.
- **Submit Order:** Display an order confirmation with the total amount.
- **Responsive Design:** Bootstrap-based layout for different screen sizes.
- **Custom Styling:** Attractive background, cards, buttons, and hover effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3

The main objective of this project is to create a user-friendly restaurant food ordering form and understand the practical use of HTML, CSS, JavaScript, and Bootstrap.

It helps demonstrate form handling, JavaScript functions, array operations, DOM manipulation, and automatic price calculation.
